# Cold Driver

Project ini terdiri dari backend Elysia dan frontend React.

## Backend

```bash
cd backend
bun install
bun run index.ts
```

Backend berjalan di `http://localhost:3000` dan membutuhkan MongoDB.

## Frontend

```bash
cd frontend
bun install
bun dev
```

Buka URL Vite yang ditampilkan terminal. Frontend menyediakan input JSON sederhana untuk membaca dan menambah data melalui endpoint `/api`.
